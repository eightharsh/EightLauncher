# eight

A minimalist Android launcher by **eightharsh**.

- Text-first Home and searchable app drawer
- Pinned notes, checklists, and reminders
- Focus mode, unlock shuffling, and local screen-time tracking
- Custom themes, fonts, and settings backup

Build a debug APK and run tests with `./gradlew assembleDebug testDebugUnitTest`.
