# Contributing to eightharsh

Maintainer: eightharsh.

Describe the problem and reproduction steps when reporting a bug. For changes, keep pull requests focused, follow STYLE_GUIDE.md, and run `./gradlew testDebugUnitTest` and `./gradlew assembleDebug`.

This fork retains the standard launcher features, including Google Fonts. Do not introduce telemetry, remote crash reporting, push messaging, or upstream branding. Keep license and copyright notices intact. Translations live in `core/ui/src/main/res/values-*/strings.xml`; use the default `values/strings.xml` as the reference.

No donation or community endpoint is configured. Use the issue tracker of the repository distributing this fork for discussions.
